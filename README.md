# Minecrawler – Unity 6 Prototyp

## Start
1. ZIP entpacken.
2. Unity Hub öffnen.
3. **Add project from disk** wählen.
4. Den Ordner `Minecrawler` auswählen.
5. Mit Unity 6 öffnen.
6. `Assets/Scenes/Game.unity` öffnen und **Play** drücken.

## Steuerung
- WASD oder Pfeiltasten: bewegen
- Maus funktioniert auch
- Zerstörbaren Fels anstoßen: abbauen
- R: Neustart

## Spielidee
Sammle Kohle. Jeder Kohlebrocken fügt deinem Zug ein neues Segment hinzu. Berührst du deinen eigenen Zug, ist der Lauf vorbei. Braune Felsen lassen sich durch Anstoßen entfernen.
